Obtenez votre Clé API Mistral AI

Guidé étape par étape pour intégrer la puissance de Mistral AI dans votre application

1
Comprendre le rôle de la clé API

La clé API est votre identifiant sécurisé pour accéder aux services de Mistral AI.

  • Authentification : Prouve que vous êtes autorisé à utiliser l'API
  • Suivi : Mistral suit vos requêtes pour facturation et monitoring
  • Sécurité : Permet le contrôle d'accès par application
  • Isolation : Créez plusieurs clés pour différents projets

⚠️ Important : Gardez votre clé secrète. Ne la communiquez pas !

2
Créer un compte Mistral AI

Visitez le site officiel de Mistral AI pour créer votre compte.

  • Accédez à console.mistral.ai
  • Cliquez sur "Sign Up"
  • Complétez vos informations (email, mot de passe)
  • Confirmez votre adresse email via le lien envoyé
  • Configurez votre profil et organisation
3
Accéder à la console et aux clés API

Rendez-vous dans la section dédiée aux clés API de la console.

  • Connectez-vous à https://console.mistral.ai
  • Dans le menu latéral, cherchez "API Keys" ou "Clés API"
  • Vous verrez vos clés existantes et pourrez en créer de nouvelles
  • Chaque clé affiche sa date de création et son dernier usage
4
Créer une nouvelle clé API

Générez une clé API dédiée à votre application.

  • Cliquez sur le bouton "+ Create API Key"
  • Donnez un nom descriptif (ex: "Mon App Production")
  • Sélectionnez les permissions et le scope si disponible
  • Confirmez la création
  • Copiez la clé immédiatement (elle ne sera plus visible après)

💡 Ensuite : Stockez votre clé dans un gestionnaire de secrets pour plus de sécurité et insérez la clef dans les "paramètres" de l'application.
